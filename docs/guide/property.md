# Property

Property is a bird's-eye picture of the home. It shows where each camera looks and where the zones you already configured sit on the ground.

The photo is downloaded once from public aerial imagery. Enter an address, or a latitude and longitude. SurvNG compares the available photos and keeps the sharpest one. When two photos are nearly the same sharpness, it keeps the newer one. The file stays on this server.

## Place cameras

A camera's make and model can supply its horizontal field of view. The catalog does not know every camera, so you can type the angle yourself.

Drag the camera onto the photo. Drag the handle at the end of the wedge to aim it and set how far the wedge reaches. North is the top of the photo.

## Place zones

Zones are still drawn on each camera's own picture in Admin. On Property, pick a zone from the list and resize the rectangle until it covers the matching part of the yard, drive, or door. That rectangle is only a drawing. It does not change detection.

If a zone is later renamed or removed, its drawing is marked stale and can be deleted.

## Detections

When an object is detected in a placed zone, the rectangle lights up and shows an icon for the object class. The highlight fades over 90 seconds. A newer detection starts the fade again.

## Notifications

Each placed camera and zone has a notification switch. Those switches are the same incident notification settings used everywhere else. Viewers can see the property view. Downloading a photo, moving placements, and changing notification switches require an administrator.
